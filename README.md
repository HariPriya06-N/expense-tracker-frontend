### 📦 Backend Repository

---

### ⚙️ Tech Stack
- React.js (Vite)
- React Router DOM
- Axios
- CSS3 
- REST API Integration with Spring Boot
- Deployed on Netlify

---

### 🚀 Features
- Full-stack expense tracking application  
- Add, update, and delete expenses  
- Filter expenses by category for better budgeting  
- Dynamic for monthly expense management  
- Smooth interaction with backend APIs for CRUD operations

### 🧠 Highlights
- Built complete frontend for expense management
